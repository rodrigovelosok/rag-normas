# rag-normas

Assistente de linha de comando que responde perguntas sobre a legislação de **arrolamento de bens e direitos**
(IN RFB nº 2.091/2022 e Lei nº 9.532/1997, arts. 64 e 64-A), **citando o artigo** de onde tirou a resposta.
Roda 100% local, com [Ollama](https://ollama.com).

> **Status:** em desenvolvimento (mini-projeto do Laboratório Introdutório da especialização em Engenharia de
> Software com IA Generativa, UFG). O README completo sai na versão 1.0.

- Requisitos: [`docs/requisitos.md`](docs/requisitos.md)
- Arquitetura: [`docs/arquitetura.md`](docs/arquitetura.md)
- Prompts usados no desenvolvimento (CO-STAR, por fase): [`PROMPTS/`](PROMPTS/)
- Procedência dos textos das normas: [`data/normas/FONTES.md`](data/normas/FONTES.md)

> Ferramenta de estudo. Não substitui a leitura da norma nem constitui parecer.
